# HL Dashboard

Dashboard di sola lettura per un conto Hyperliquid e per la strategia Trend giornaliera (BTC, ETH, SOL).

- Legge solo dati **pubblici** dall'API `/info` di Hyperliquid: serve l'indirizzo pubblico (0x…), mai chiavi.
- L'indirizzo resta salvato solo nel browser di chi apre la pagina.
- La pagina non può inviare ordini. Non è consulenza finanziaria.
